# Train Projector

RTM車両パックのZIPから車両を一覧表示し、背景透明の投影PNGを保存する静的Webです。特定の車種・作者・パック名には依存しません。

`index.html`を新しいChromeまたはEdgeで開いてください。ローカルファイルから直接使用できます。ビルド・Webサーバー・外部CDNは不要です。このフォルダ全体を静的ホスティングに配置することもできます。

## 使い方

1. 車両パックのZIPをドロップするか、「ファイルを選ぶ」で指定します。前提・共通パックも一緒に読み込んでください。JAR内のモデルリソースも参照できます。
2. 車両一覧から選択します。名前とJSON名で検索できます。モデル形式と描画対応状況も一覧に表示します。
3. X・Y・Zの正／負側から見る6方向の正投影を選びます。
4. 「マテリアルの描画設定」と「パーツの表示／非表示」で見た目を調整します。初期表示ではMQO編集時の非表示設定を使わず、全部品を描画します。
5. 出力の長辺（1024／2048／4096px）を選び、「透過PNGを保存」を押します。縦横比はモデルの寸法に合わせます。市松模様はPNGには入りません。

ZIPを追加すると、読み込み済みのリソースと合わせて参照先を検索します。同じリソースが複数ある場合は、JSONと同じZIP・同じassetsルートを優先し、それ以外は後から読み込んだパックを優先します。名前空間を省略したパスはminecraftを優先し、見つからない場合はJSON側の名前空間も検索します。

## マテリアルとパーツの調整

材質名・テクスチャ名でマテリアルを検索し、次の項目を変更できます。車体・各台車の材質を個別に扱います。

- 表示：そのマテリアルを使う面を表示／非表示にします。
- AlphaBlend：半透明画素を描画します。OFFでは完全に不透明な画素のみ描画します。初期値はJSONのAlphaBlend指定を反映し、MTLを使う場合はONです。
- Light：元テクスチャを陰影なしで描く簡易発光です。照明のプレビューとして初期値はOFFです。RTMのLight用テクスチャやJSの発光部品制御を実行する機能ではありません。
- 両面：背面カリングを外します。初期値はJSONのdoCullingを反映します。
- 不透明度：マテリアルのアルファ値を0〜100%で調整します。テクスチャのアルファ値に乗算されます。半透明の出力にはAlphaBlendをONにしてください。

パーツ一覧では、個別のチェック、名前検索、検索結果の一括表示・非表示・反転、読み込み時の状態への復元ができます。マテリアルにも「読み込み時に戻す」があります。

設定はプレビューと出力PNGに反映され、車両を切り替えても同じページを開いている間は車両ごとに保持されます。ページを閉じるか「すべてクリア」を押すと消えます。設定変更による元ZIP・JSONへの書き込みは行いません。

## 対応範囲

| 対象 | 対応内容 |
| --- | --- |
| MQO | テキスト形式、材質、UV、スムージング、オブジェクト変換・階層、ミラー |
| OBJ | 頂点、UV、法線、グループ、負のインデックス、MTLの色・透過・拡散テクスチャ |
| MQOZ | ZIP内部のMQOを展開。テクスチャはRTMのJSON・外部リソースから解決 |
| JSON | trainModel2と旧trainModel＋trainTextureを正規化 |
| 台車 | bogieModel3、前後共通のbogieModel2、旧bogieModel＋bogieTexture |
| 座標 | MQOのcm／OBJのモデル座標、bogiePos、後方台車の180度回転、JSONのscale／offset |
| リソース | assets配下の任意の名前空間、models/jsonとjson、旧models・textures構成 |
| 配布形式 | 複数ZIP、JAR内のリソース、ZIP64、入れ子ZIP（2階層まで） |
| 画像 | 元テクスチャ、透明度、mcmetaのblur/clamp、透過PNG出力 |

テクスチャの内容を補修する処理はありません。元ファイルは変更しません。

## 現在の制限

**全てのRTMパックをゲーム内と同じ外観で描画できる段階ではありません。**

- 車両JSは実行しません。JSによる部品の排他表示・アニメーション・カスタムボタン・発光制御には未対応です。部品の表示を手動で調整できます。
- Java製モデル（.class）は描画未対応です。車両一覧には表示し、未対応であることを示します。台車だけがJava製の場合は、車体を描画して台車の省略を読み込み情報に表示します。
- 照明は簡易的な固定照明です。ゲームの光源、シェーダー、フレア、ロールサイン生成などのゲーム側追加描画は再現しません。
- 交差する半透明面の描画順は部品単位の近似です。自己交差した多角形など、正常に三角形分割できない面は近似します。
- 暗号化・分割されたZIPには未対応です。圧縮方式はSTORE／DEFLATEに対応し、展開時にサイズとCRC32を確認します。1ファイルの展開上限は256MBです。大きなパックはブラウザのメモリ・GPU上限にも依存します。
- 前提パック内のモデルやテクスチャは、そのパックも読み込む必要があります。不足テクスチャは紫のチェックで示し、不足モデルはファイル名を表示します。

RTM本体の標準形式を広く読み込める構成です。独自Modの追加形式、Java描画、Java APIに依存した任意の車両JSまで完全に再現するには、それぞれの実行環境・互換処理が別途必要です。

## ファイル

- index.html：画面構成
- styles.css：装飾とレイアウト
- zip.js：ZIP・ZIP64、名前空間、リソースパス、JSONの読み込み
- config.js：新旧RTM車両設定の正規化と対応状況の判定
- model.js：MQO解析、三角形分割、メッシュ生成
- obj.js：OBJ・MTL解析
- renderer.js：WebGL 2による透過描画とPNG生成
- app.js：一覧、リソース解決、操作、保存

パックのJS・Javaクラス・HTMLは実行せず、ファイルをブラウザ内で解析します。外部への送信は行いません。
